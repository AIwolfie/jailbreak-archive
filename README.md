## ▸ Overview

This repository is a **personal, structured archive** of jailbreak and adversarial
prompt techniques collected against large language models. Each entry is
versioned, tagged, and reproducible. The goal is a clean, citable record — not a
dump.

Every entry captures:

- **What** the prompt was — verbatim, no paraphrase.
- **Where** it ran — model, version, interface, session config.
- **Why** it worked — mechanism, instruction-hierarchy analysis.
- **What** would block it — mitigations.

<div align="center">

| Signal | Meaning |
|:------:|:--------|
| ✅ | Reproduced on the stated version |
| ⚠️ | Reported, not independently reproduced |
| ❌ | Patched / no longer effective |
| 🔒 | Withheld — sensitive, index only |
